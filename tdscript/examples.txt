Each task defines:

TASK 1: BME280 Chip ID Read
================================================================================
- ID: 1
- Title: BME280 Chip ID Read
- Interface: I2C (Address: 0x76 / 118, Register: 0xD0 / 208, Length: 1 byte)
- Description: Read Bosch BME280 Chip ID via I2C and print the result.
- Expected Keywords: ["96", "0x60"]
- Expected Output: [0x60] or 96

--- TDscript AI-First (v1.4.0 Hex) ---
```tdscript
let id = I2C.read(0x76, 0xD0, 1);
print(id);
```

--- TDscript Base (v1.4.0 Decimal) ---
```tdscript
let id = I2C.read(118, 208, 1);
print(id);
```

--- Python Reference ---
```python
from mock_hw import I2C
val = I2C.read(0x76, 0xD0, 1)
print(val)
```

--- C++ Reference ---
```cpp
#include "mock_hw.hpp"
#include <iostream>

int main() {
    auto val = I2C::read(0x76, 0xD0, 1);
    std::cout << val[0] << std::endl;
    return 0;
}
```

TASK 2: Modbus Boiler Temperature Control
================================================================================
- ID: 2
- Title: Modbus Boiler Temperature Control
- Interface: Modbus TCP (Host: "127.0.0.1", Register 100: Boiler Temp, Register 101: Pump Status)
- Description: Read boiler temperature from Modbus register 100 ('127.0.0.1') and pump status from register 101. If temperature > 250, write pump status 0 (OFF).
- Expected Keywords: ["245", "100", "101"]

--- TDscript AI-First ---
```tdscript
let temp = PLC.modbusRead("127.0.0.1", 100);
let pump = PLC.modbusRead("127.0.0.1", 101);
print(temp);
if (temp > 250) {
    PLC.modbusWrite("127.0.0.1", 101, 0);
}
```

--- Python Reference ---
```python
from mock_hw import PLC
temp = PLC.modbus_read("127.0.0.1", 100)
pump = PLC.modbus_read("127.0.0.1", 101)
print(f"temp={temp}, pump={pump}")
if temp > 250:
    PLC.modbus_write("127.0.0.1", 101, 0)
```

TASK 3: Safe I2C Poll with Watchdog Emergency
================================================================================
- ID: 3
- Title: Safe I2C Poll with Watchdog Emergency
- Interface: I2C (0x76, 0xD0) + Watchdog Subsystem
- Description: Safely read I2C sensor at address 0x76 (register 0xD0, 1 byte). If read returns error or null, call WATCHDOG.emergencyStop(), otherwise print 'POLL_OK'.
- Expected Keywords: ["POLL_OK", "0x76"]

--- TDscript AI-First ---
```tdscript
let data = I2C.read(0x76, 0xD0, 1);
if (data == null) {
    WATCHDOG.emergencyStop();
} else {
    print("POLL_OK");
}
```

--- Python Reference ---
```python
from mock_hw import I2C, WATCHDOG
data = I2C.read(0x76, 0xD0, 1)
if not data:
    WATCHDOG.emergency_stop()
else:
    print("POLL_OK")
```

TASK 4: Modbus 5-Iteration Loop with Watchdog Feed
================================================================================
- ID: 4
- Title: Modbus 5-Iteration Loop with Watchdog Feed
- Interface: Modbus TCP + Watchdog Hardware Feed
- Description: Execute a loop for 5 iterations: in each iteration read Modbus register 100 and call WATCHDOG.feed().
- Expected Keywords: ["feed", "100"]

--- TDscript AI-First ---
```tdscript
var i = 0;
while (i < 5) {
    let v = PLC.modbusRead("127.0.0.1", 100);
    WATCHDOG.feed();
    print(v);
    i = i + 1;
}
```

--- Python Reference ---
```python
from mock_hw import PLC, WATCHDOG
for i in range(5):
    val = PLC.modbus_read("127.0.0.1", 100)
    WATCHDOG.feed()
    print(f"feed:{i}, val:{val}")
```

TASK 9: Combined Dual-Sensor Verification
================================================================================
- ID: 9
- Title: Combined Dual-Sensor Verification
- Interface: I2C + Modbus TCP + Watchdog Subsystem
- Description: Read BME280 Chip ID (0x76) and Modbus register 100. If both are valid, print 'SYSTEM_OK', otherwise call WATCHDOG.emergencyStop().
- Expected Keywords: ["SYSTEM_OK"]

--- TDscript AI-First ---
```tdscript
let id = I2C.read(0x76, 0xD0, 1);
let reg = PLC.modbusRead("127.0.0.1", 100);
if (id != null && reg != null) {
    print("SYSTEM_OK");
} else {
    WATCHDOG.emergencyStop();
}
```

--- Python Reference ---
```python
from mock_hw import I2C, PLC, WATCHDOG
chip = I2C.read(0x76, 0xD0, 1)
mb = PLC.modbus_read("127.0.0.1", 100)
if chip and mb is not None:
    print("SYSTEM_OK")
else:
    WATCHDOG.emergency_stop()
```
