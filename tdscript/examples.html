🛠️ 10 эталонных сценариев автоматизации

Эти 10 задач легли в основу официального сравнительного бенчмарка TDscript против Python, C++, Lua, JavaScript и Kotlin. Они охватывают полный цикл промышленной автоматизации: опрос шины I2C, протокол Modbus TCP, беспроводной BLE, сетевой пинг, безопасный сторож Watchdog и аппаратную изоляцию.

Задача 1: Чтение Chip ID климатического сенсора Bosch BME280 по I2C Шина I2C

Постановка: Прочитать 1 байт из регистра 0xD0 чипа BME280 по адресу 0x76 и вывести полученный идентификатор микросхемы (ожидается 0x60 / 96). 

// Решение на TDscript v1.4.0 (Студия, поддержка hex-литералов)
let chip = 0x76;
let reg = 0xD0;
let bytes = I2C.read(chip, reg, 1);
print(bytes); // Выведет: [0x60]
В классическом синтаксисе TDscript 1.0.1 (Tdroid): let bytes = I2C.read(118, 208, 1); print(bytes); (используются десятичные 118 и 208).

Задача 2: Modbus TCP контроль температуры котла и защита насоса Промышленный Modbus PLC

Постановка: Прочитать температуру из Holding Register 100 контроллера (127.0.0.1) и текущий статус насоса из регистра 101. Если температура превышает аварийный порог 250°C, принудительно отключить насос, записав 0 в регистр 101. 

let host = "127.0.0.1";
let temp = PLC.modbusRead(host, 100);
let pump = PLC.modbusRead(host, 101);

if (temp > 250) {
    PLC.modbusWrite(host, 101, 0);
    print("EMERGENCY_SHUTDOWN: Pump stopped");
} else {
    print("TEMPERATURE_NORMAL");
}

Задача 3: Безопасный опрос сенсора с аварийным остановом Watchdog Fail-Safe Безопасность

Постановка: Выполнить безопасный опрос регистра 0xD0 сенсора 0x76. Если чтение возвращает ошибку или null, немедленно вызвать WATCHDOG.emergencyStop() для предотвращения повреждения оборудования. При успехе вывести POLL_OK. 

let chip = 0x76;
let reg = 0xD0;
let data = I2C.read(chip, reg, 1);

if (data == null) {
    WATCHDOG.emergencyStop();
} else {
    print("POLL_OK: Sensor healthy at 0x76");
}

Задача 4: Циклический опрос Modbus с подпиткой аппаратного сторожа Watchdog Feed

Постановка: Выполнить цикл из 5 итераций: на каждом шаге опрашивать датчик (регистр 100) и регулярно подпитывать аппаратный сторожевой таймер через WATCHDOG.feed(). 

var i = 0;
while (i < 5) {
    let val = PLC.modbusRead("127.0.0.1", 100);
    WATCHDOG.feed(); // Сигнал аппаратной подпитки
    print("Iter: " + i + ", Val: " + val);
    i = i + 1;
}

Задача 5: Локализованное оповещение через LString Интерполяция 109 языков

Постановка: Сформировать локализованное уведомление с ключом ALERT_TEMP и динамическим параметром temp = 24.5. В TDscript сложение строк через + строго запрещено (ошибка TDS_E105), поэтому используется безопасная подстановка. 

let temp = 24.5;
// Интерполяция {temp} из локального скоупа переменных
let notification = L"ALERT_TEMP:Current temperature is {temp}C";
print(notification);

Задача 6: Подключение и запрос данных по Bluetooth LE (BLE) Беспроводные шины

Постановка: Подключиться к периферийному BLE-устройству с идентификатором sensor_01, отправить команду READ и распечатать полученную телеметрию. 

let device = "sensor_01";
let connected = BLE.connect(device);

if (connected == true) {
    let telemetry = BLE.send(device, "READ");
    print("BT_OK: Received " + telemetry);
} else {
    print("BLE_CONNECTION_FAILED");
}

Задача 7: Сетевая диагностика Ping перед запросом к Modbus ПЛК Сетевая надежность

Постановка: Перед отправкой промышленных пакетов выполнить ICMP ping узла 192.168.1.50. Если узел доступен (RTT > 0), запросить регистр 100. 

let targetIp = "192.168.1.50";
let rtt = NET.ping(targetIp);

if (rtt > 0) {
    let val = PLC.modbusRead(targetIp, 100);
    print("Host reachable (" + rtt + " ms). Value: " + val);
} else {
    print("Host unreachable");
}

Задача 8: Запись конфигурационного байта в регистр чипа по I2C I2C Конфигурация

Постановка: Записать управляющий байт режима измерений в регистр 0xF4 датчика 0x76 и распечатать статус успешности операции. 

let chip = 0x76;
let ctrlReg = 0xF4;
let modeByte = 0x27; // Режим Normal, oversampling x1
let status = I2C.write(chip, ctrlReg, modeByte);
print("I2C_WRITE_0x76_0xF4: " + status);

Задача 9: Комплексная валидация дуальной системы (I2C + Modbus) Синхронный контроль

Постановка: Проверить Chip ID BME280 (0x76) и значение регистра Modbus 100. Если оба источника исправны, выдать SYSTEM_OK, иначе активировать аварийный останов WATCHDOG.emergencyStop(). 

let chipData = I2C.read(0x76, 0xD0, 1);
let modbusVal = PLC.modbusRead("127.0.0.1", 100);

if (chipData != null && modbusVal != null) {
    print("SYSTEM_OK: Dual sensors verified");
} else {
    WATCHDOG.emergencyStop();
}

Задача 10: Пространственная изоляция CapabilityScope и самоисправление AI-First Песочница

Постановка: Скрипт должен работать строго в рамках белого списка CapabilityScope (разрешён только адрес 0x76). Если скрипт попытается обратиться к запрещенному адресу (например, 0x68), хост заблокирует вызов. ИИ-агент перехватывает сбой и перенаправляет опрос на 0x76. 

// Попытка обращения к неавторизованному адресу 0x68:
let invalidRes = I2C.read(0x68, 0x00, 1); // Возвратит null (SCOPE_VIOLATION)

// Автоматическое переключение на разрешённый адрес из белого списка:
let validRes = I2C.read(0x76, 0xD0, 1);
print("SUCCESS_FALLBACK_0x76: " + validRes);
