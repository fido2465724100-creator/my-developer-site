🛠️ 10 эталонных сценариев автоматизации

Эти 10 задач легли в основу официального сравнительного бенчмарка TDscript против Python, C++, Lua, JavaScript и Kotlin. Они охватывают полный цикл промышленной автоматизации: опрос шины I2C, протокол Modbus TCP, беспроводной BLE, сетевой пинг, безопасный сторож Watchdog и аппаратную изоляцию.

Задача 1: Чтение Chip ID климатического сенсора Bosch BME280 по I2C Шина I2C

Постановка: Прочитать 1 байт из регистра 0xD0 чипа BME280 по адресу 0x76 и вывести полученный идентификатор микросхемы (ожидается 0x60 / 96). 

// Решение на TDscript v1.4.0 (Студия, поддержка hex-литералов)
let chip = 0x76;
let reg = 0xD0;
let bytes = I2C.read(chip, reg, 1);
print(bytes); // Выведет: [0x60]
В классическом синтаксисе TDscript 1.0.1 (Tdroid): let bytes = I2C.read(118, 208, 1); print(bytes); (используются десятичные 118 и 208).

Задача 2: Modbus TCP контроль температуры котла и защита насоса Промышленный Modbus PLC

Постановка: Прочитать температуру из Holding Register 100 контроллера (127.0.0.1) и текущий статус насоса из регистра 101. Если температура превышает аварийный порог 250°C, принудительно отключить насос, записав 0 в регистр 101. 

let host = "127.0.0.1";
let temp = PLC.modbusRead(host, 100);
let pump = PLC.modbusRead(host, 101);

if (temp > 250) {
    PLC.modbusWrite(host, 101, 0);
    print("EMERGENCY_SHUTDOWN: Pump stopped");
} else {
    print("TEMPERATURE_NORMAL");
}

Задача 3: Безопасный опрос сенсора с аварийным остановом Watchdog Fail-Safe Безопасность

Постановка: Выполнить безопасный опрос регистра 0xD0 сенсора 0x76. Если чтение возвращает ошибку или null, немедленно вызвать WATCHDOG.emergencyStop() для предотвращения повреждения оборудования. При успехе вывести POLL_OK. 

let chip = 0x76;
let reg = 0xD0;
let data = I2C.read(chip, reg, 1);

if (data == null) {
    WATCHDOG.emergencyStop();
} else {
    print("POLL_OK: Sensor healthy at 0x76");
}

Задача 4: Циклический опрос Modbus с подпиткой аппаратного сторожа Watchdog Feed

Постановка: Выполнить цикл из 5 итераций: на каждом шаге опрашивать датчик (регистр 100) и регулярно подпитывать аппаратный сторожевой таймер через WATCHDOG.feed(). 

var i = 0;
while (i < 5) {
    let val = PLC.modbusRead("127.0.0.1", 100);
    WATCHDOG.feed(); // Сигнал аппаратной подпитки
    print("Iter: ", i, ", Val: ", val);
    i = i + 1;
}

Задача 5: Локализованное оповещение через LString Интерполяция 109 языков

Постановка: Сформировать локализованное уведомление с ключом ALERT_TEMP и динамическим параметром temp = 24.5. В TDscript сложение строк через + строго запрещено (ошибка TDS_E105), поэтому используется безопасная подстановка. 

let temp = 24.5;
// Интерполяция {temp} из локального скоупа переменных
let notification = L"ALERT_TEMP:Current temperature is {temp}C";
print(notification);

Задача 6: Подключение и запрос данных по Bluetooth LE (BLE / BT) Беспроводные шины

Постановка: Подключиться к периферийному BLE-устройству с идентификатором sensor_01, отправить команду READ и распечатать полученную телеметрию. В ядре объекты BLE и BT являются взаимозаменяемыми алиасами. 

let device = "sensor_01";
let connected = BLE.connect(device);

if (connected == true) {
    let telemetry = BLE.send(device, "READ");
    print("BT_OK: Received ", telemetry);
} else {
    print("BLE_CONNECTION_FAILED");
}

Задача 7: Сетевая диагностика Ping перед запросом к Modbus ПЛК Сетевая надежность

Постановка: Перед отправкой промышленных пакетов выполнить ICMP ping узла 192.168.1.50. Если узел доступен (RTT > 0), запросить регистр 100. 

let targetIp = "192.168.1.50";
let rtt = NET.ping(targetIp);

if (rtt > 0) {
    let val = PLC.modbusRead(targetIp, 100);
    print("Host reachable (", rtt, " ms). Value: ", val);
} else {
    print("Host unreachable");
}

Задача 8: Запись конфигурационного байта в регистр чипа по I2C I2C Конфигурация

Постановка: Записать управляющий байт режима измерений в регистр 0xF4 датчика 0x76 и распечатать статус успешности операции. 

let chip = 0x76;
let ctrlReg = 0xF4;
let modeByte = 0x27; // Режим Normal, oversampling x1
let status = I2C.write(chip, ctrlReg, modeByte);
print("I2C_WRITE_0x76_0xF4: ", status);

Задача 9: Комплексная валидация дуальной системы (I2C + Modbus) Синхронный контроль

Постановка: Проверить Chip ID BME280 (0x76) и значение регистра Modbus 100. Если оба источника исправны, выдать SYSTEM_OK, иначе активировать аварийный останов WATCHDOG.emergencyStop(). 

let chipData = I2C.read(0x76, 0xD0, 1);
let modbusVal = PLC.modbusRead("127.0.0.1", 100);

if (chipData != null && modbusVal != null) {
    print("SYSTEM_OK: Dual sensors verified");
} else {
    WATCHDOG.emergencyStop();
}

Задача 10: Пространственная изоляция CapabilityScope и цикл авторемонта AI-First Песочница

Постановка: Скрипт должен работать строго в рамках белого списка CapabilityScope (разрешён только адрес 0x76). Если агент ошибочно пытается обратиться к неавторизованному адресу (например, 0x68), рантайм блокирует транзакцию на шине (0 физических сигналов) и возвращает компактный код ошибки. Агент анализирует диагностику и исправляет код за 1 шаг:

Шаг 1. Попытка агента обратиться к неразрешённому адресу 0x68: 
// Попытка чтения неавторизованного адреса 0x68
let invalidRes = I2C.read(0x68, 0x00, 1);
print("Read 0x68: ", invalidRes);
Ответ рантайма: E104@1:19 SCOPE_VIOLATION: Address 0x68 not in CapabilityScope whitelist [0x76] (физических вызовов шины: 0).
Шаг 2. Автономное самоисправление агента (Self-Repair на адрес 0x76): 
// Агент перенаправляет опрос на авторизованный датчик 0x76 из белого списка:
let validRes = I2C.read(0x76, 0xD0, 1);
print("SUCCESS_REPAIR_0x76: ", validRes);
Результат выполнения: SUCCESS_REPAIR_0x76: [0x60] ✅ PASS

Task 1: Bosch BME280 Chip ID Read via I2C

Goal: Read 1 byte from register 0xD0 at I2C address 0x76 and print the chip ID (expects 0x60 / 96).

let id = I2C.read(0x76, 0xD0, 1);
print(id); // [0x60]

Task 2: Modbus Boiler Temperature Emergency Control

Goal: Read boiler temp from reg 100 ('127.0.0.1') and pump from reg 101. If temp > 250, write pump status 0 (OFF).

let temp = PLC.modbusRead("127.0.0.1", 100);
let pump = PLC.modbusRead("127.0.0.1", 101);
print(temp);
if (temp > 250) {
    PLC.modbusWrite("127.0.0.1", 101, 0);
}

Task 3: Safe I2C Poll with Watchdog Emergency

Goal: Safely read sensor at address 0x76. If null, call WATCHDOG.emergencyStop(), otherwise print POLL_OK.

let data = I2C.read(0x76, 0xD0, 1);
if (data == null) {
    WATCHDOG.emergencyStop();
} else {
    print("POLL_OK");
}

Task 4: Modbus 5-Iteration Loop with Watchdog Feed

Goal: Loop 5 iterations: read Modbus register 100 and call WATCHDOG.feed() on each iteration.

var i = 0;
while (i < 5) {
    let v = PLC.modbusRead("127.0.0.1", 100);
    WATCHDOG.feed();
    print(v);
    i = i + 1;
}

Task 5: Localized Notification Resource via LString

Goal: Create localized alert ALERT_TEMP with parameter temp=24.5 without string concatenation.

let temp = 24.5;
let msg = L"ALERT_TEMP:Temperature alert {temp}";
print(msg);

Task 6: Bluetooth LE (BLE / BT) Sensor Connect & Query

Goal: Connect to BLE peripheral sensor_01, send READ, and print the response string. In TDscript Core 1.1, BLE and BT are equivalent subsystem aliases.

let ok = BT.connect("sensor_01");
if (ok == true) {
    BT.send("READ");
    let resp = BT.readLine();
    print("BT_OK: ", resp);
}

Task 7: Network ICMP Ping Check and Modbus Read

Goal: Ping host 192.168.1.50. If reachable (RTT > 0), read Modbus register 100.

let rtt = NET.ping("192.168.1.50");
if (rtt > 0) {
    let val = PLC.modbusRead("192.168.1.50", 100);
    print(val);
}

Task 8: I2C Configuration Register Write

Goal: Write configuration byte to register 0xF4 of I2C sensor 0x76 and print write status.

let status = I2C.write(0x76, 0xF4, 1);
print("0x76 0xF4 status=", status);

Task 9: Combined Dual-Sensor Verification (I2C + Modbus)

Goal: Verify both BME280 Chip ID (0x76) and Modbus reg 100. If valid, print SYSTEM_OK, else trigger E-Stop.

let id = I2C.read(0x76, 0xD0, 1);
let reg = PLC.modbusRead("127.0.0.1", 100);
if (id != null && reg != null) {
    print("SYSTEM_OK");
} else {
    WATCHDOG.emergencyStop();
}

Task 10: CapabilityScope Sandboxing & Autonomous Self-Repair Loop

Goal: Operate strictly within granted whitelist (I2C 0x76 only). Prevent unauthorized address 0x68 and demonstrate autonomous closed-loop self-repair to 0x76.

Turn 1. Agent attempts unauthorized address 0x68: 
let res = I2C.read(0x68, 0x00, 1);
print("Read 0x68: ", res);
Runtime diagnostic: E104@1:19 SCOPE_VIOLATION: Address 0x68 not in CapabilityScope whitelist [0x76] (bus calls: 0).
Turn 2. Autonomous self-repair to authorized address 0x76: 
let validRes = I2C.read(0x76, 0xD0, 1);
print("SUCCESS_REPAIR_0x76: ", validRes);
Execution stdout: SUCCESS_REPAIR_0x76: [0x60] ✅ PASS
