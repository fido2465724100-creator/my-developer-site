🛠️ Среда разработки TDscript Studio Версия 1.1.0

TDscript Studio — кроссплатформенная IDE нового поколения, созданная специально для аппаратных инженеров, робототехников и разработчиков встроенных систем. Студия доступна как в виде десктопного оконного приложения на Compose Desktop (Linux / Windows), так и в мобильной редакции для Android с поддержкой прямого подключения к микросхемам через USB-OTG и Bluetooth LE.

🤖 Автономный ИИ-агент (Agentic Loop)

Замкнутый цикл: автоматический опрос активных шин (probe()), генерация кода по текстовому описанию задачи, выполнение в песочнице AiHardwareSandbox, отлов JSON-ошибок компилятора и автоматическое исправление кода (до 3–5 итераций) с поддержкой локальных LLM (Ollama, LM Studio).

🌐 Живой проектор языков (RU / EN / DE)

Мгновенное посимвольное переключение отображения ключевых слов в редакторе (пусть/sei/let, если/wenn/if) с сохранением целостности строковых литералов и комментариев.

🔬 Монитор регистров и шин

Встроенная симуляция чипа Bosch BME280 (@ 0x76) и ПЛК Modbus TCP (@ 127.0.0.1:502). Живое отображение значений регистров в реальном времени.

📱 Мобильная среда Android

Работа на планшетах и смартфонах в полевых условиях. Прямое управление платами и датчиками через переходники USB-UART / USB-I2C по протоколу USB Host OTG.

💻 Работа в режиме консоли (CLI / Headless)

TDscript Studio поддерживает запуск без графической оболочки (0 KB VRAM / Headless) на серверах, платах Raspberry Pi и в CI/CD пайплайнах: 

# Запуск скрипта в консольном режиме с виртуальной песочницей:
java -jar tdscript-studio-linux-x64-1.1.0.jar --cli --script=myscript.tds

# Запуск в режиме фонового сервера автоматизации:
./tdscript-studio/bin/tdscript-studio --cli --daemon --port=8080
