⚡ О бенчмарке Тест №3 (Официальный)

Цель бенчмарка — проверить пригодность современных компактных локальных моделей искусственного интеллекта (3B–9B параметров) для генерации надёжного и компактного кода автоматизации физических микросхем, промышленных контроллеров и робототехники.

Тестирование проводилось в живом режиме на llama-server (llama.cpp) с моделью Qwen 3.5 9B Instruct с аппаратным CUDA-ускорением на видеокарте GeForce GTX 1070 по всем 7 целевым языкам/рантаймам на 10 идентичных аппаратно-сетевых задачах (70 задач суммарно, 148 попыток).

💡 Почему TDscript превосходит традиционные языки в задачах автоматизации

📏 Экстремальная компактность (5.6 строк LOC)

TDscript код в 1.7 раза компактнее Python (5.6 vs 9.7 строк) и в 2.7 раза компактнее C++ (5.6 vs 15.0 строк). Чем меньше строк генерирует LLM, тем ниже вероятность галлюцинаций и тем быстрее отрабатывает генерация.

⚡ Экономия токенов на 45% (Cost / Success)

Внедрение сжатого формата ошибок repair (E104@line:col exp=0x76 got=0x68) снизило расход токенов на успешное решение с 4149.9 до 2275.2 токенов.

🛡️ 100% Синтаксическая гарантия с GBNF

Использование формальной грамматики GBNF в llama.cpp / Ollama полностью исключает синтаксические ошибки при генерации кода локальными моделями.

🚀 Нулевой оверхед (0 KB VRAM / Headless)

В отличие от Python, требующего внешних библиотек и тяжелого рантайма, TDscript исполняется детерминированно в компактном встраиваемом движке без зависимостей.

🔌 Настройка и подключение к локальным LLM (Ollama, LM Studio)

В TDscript Studio встроен легковесный HTTP-клиент, совместимый с OpenAI API (без сторонних тяжелых SDK): 

# Запуск Ollama:
ollama run qwen2.5:7b

# Подключение из TDscript Studio:
Endpoint URL: http://127.0.0.1:11434/v1
Model Name:   qwen2.5:7b

# Запуск llama-server с поддержкой GBNF-грамматики TDscript:
./llama-server -m models/qwen3.5-9b.gguf --port 8765 --grammar-file docs/tdscript-core-1.1.gbnf
