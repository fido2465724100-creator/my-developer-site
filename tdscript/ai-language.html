💡 Манифест: Зачем нужен специальный язык для ИИ?

Все существующие популярные языки программирования (C/C++, Python, JavaScript, Rust, Kotlin) создавались для человека:

  • Они оптимизированы под человеческое восприятие, гибкие абстракции, динамические импорты и сложный синтаксический сахар.
  • Для человека важны тысячи сторонних пакетов (PyPI, npm), но для компактной локальной нейросети (3B–9B параметров) это становится непреодолимым барьером.

В автономном цикле управления физическим оборудованием и робототехникой (Agentic Loop) традиционные языки страдают от фундаментальных проблем:

❌ Галлюцинации библиотек и импортов

В Python для работы с I2C модель может галлюцинировать import smbus, smbus2, adafruit_bme280 или несуществующие методы. Ошибка импорта ломает весь цикл исполнения.

❌ Избыточный шаблонный код (Boilerplate)

В C++ или Kotlin простая задача чтения регистра требует 15–20 строк обвязки (структуры, дескрипторы, includes, try-catch). Чем длиннее генерация, тем выше вероятность сбоя и тем больше токенов тратится впустую.

❌ Угроза аварии железа (Scope Leaks)

Традиционные языки не имеют встроенных аппаратных ACL. Ошибившись в адресе устройства (например, записав в 0x68 вместо 0x76), модель может необратимо сжечь подключенный датчик или привод.

❌ Неинформативные стектрейсы

Многостраничные стектрейсы Python или ошибки линковки C++ перегружают контекстное окно модели, не давая четкой инструкции, какую именно строку и аргумент нужно исправить.

TDscript AI-First (Experimental) решает эти проблемы на фундаментальном уровне. Это первый специализированный язык, где генератором кода является нейросеть, а исполнителем — строгая песочница безопасности.

🛡️ 6 столпов архитектуры TDscript AI-First

1. Экстремальный минимализм токенов (3.5–5.6 LOC)

Любая задача автоматизации выражается в 3–5 строках чистого кода. Это в 2–3 раза компактнее Python и C++. Чем меньше токенов требуется сгенерировать модели, тем выше скорость инференса и ниже вероятность галлюцинаций.

2. Zero Imports — Аппаратные примитивы в ядре

В языке нет ключевых слов import, #include или require. Примитивы I2C, MODBUS, BLE, PING и WATCHDOG встроены в грамматику. Модель физически не может "забыть подключить библиотеку".

3. Аппаратный мандат безопасности (CapabilityScope)

Перед запуском кода ядро передает скрипту мандат безопасности: разрешенные адреса I2C, порты и диапазоны регистров Modbus. Если модель пытается обратиться к неразрешенному узлу (например, 0x68 вместо 0x76), рантайм моментально блокирует вызов и выдает ошибку безопасности без физического обращения к шине.

4. Машиночитаемый протокол диагностики ошибок

Вместо "человеческих" стектрейсов рантайм возвращает строгий компактный JSON диагностического протокола: {"code":"TDS_E104","expected":"0x76","actual":"0x68","suggestion":"..."}. Модель мгновенно понимает причину ошибки и устраняет её с первой итерации.

5. 100% Синтаксическая гарантия через GBNF

Грамматика TDscript Core 1.1 формализована в эталонном файле GBNF (GGML BNF). При генерации через llama-server или Ollama движок на уровне семплирования токенов исключает любые синтаксические ошибки (0% Syntax Errors).

6. Мультиязычная проекция кода (Code Projection)

Модель генерирует код на лаконичном английском синтаксисе (var, if, print), а инженер-оператор на заводе в Германии или России может просматривать и редактировать его на немецком (sei, wenn, drucken) или русском (пусть, если, печать) в реальном времени благодаря обратимой AST-проекции.

📖 Спецификация синтаксиса TDscript AI-First

1. Литералы и типы данных

  • Числа: Десятичные (42, 3.14) и шестнадцатеричные адреса и байты (0x76, 0xD0, 0xFF).
  • Строки: Одинарные и двойные кавычки ("POLL_OK", 'sensor_01').
  • Логические: true, false.
  • Массивы байт (ByteArray): Возвращаются методами ввода-вывода (I2C.read). Доступ по индексу: data[0], размер: data.length.
  • Локализованные ресурсы (LString): LString("ALERT_TEMP", temp=24.5). Не допускает прямой конкатенации строк, что исключает ошибки локализации.

2. Управляющие конструкции

// Объявление переменных (неизменяемые val и изменяемые var)
val targetAddr = 0x76
var counter = 0

// Ветвление
if (temp > 250) {
    MODBUS.write('127.0.0.1', 101, 0)
} else {
    print("Normal mode")
}

// Циклы
while (counter < 5) {
    WATCHDOG.feed()
    counter = counter + 1

4. Протокол самоисправления ошибок (Self-Repair Diagnostic Protocol)

Когда сгенерированный ИИ-моделью код нарушает правила безопасности или содержит синтаксическую ошибку, компилятор не падает со стектрейсом, а возвращает структурированный контекст исправления: 

{
  "status": "ERROR",
  "error_code": "TDS_E104_SCOPE_VIOLATION",
  "line": 1,
  "column": 19,
  "message": "Access to I2C address 0x68 is forbidden by CapabilityScope",
  "expected": "0x76",
  "actual": "0x68",
  "suggestion": "Replace I2C device address 0x68 with authorized address 0x76"
}

В сжатом режиме (Compact Repair), используемом в TDscript Studio для экономии токенов, ошибка передается в виде: E104@1:19 exp=0x76 got=0x68. Подобная компактная обратная связь позволяет локальной модели исправить код за 1 итерацию, снижая расход токенов на 45%.

🤖 Интеграция в автономный цикл агента (Agentic Loop)

В модуле com.tdscript.studio.agent реализован полный цикл автономной генерации и исполнения:

  1. Discovery Snapshot: Среда опрашивает аппаратный стенд (sandbox.probe()) и передает модели контекст доступных датчиков: [I2C @ 0x76 (BME280), Modbus @ 127.0.0.1:502 (Regs 100..200)].
  2. LLM Generation: Модель генерирует компактный скрипт на TDscript AI-First (с GBNF-валидацией).
  3. Sandbox Verification: Скрипт выполняется в изолированной песочнице с эмуляцией шин и проверкой CapabilityScope.
  4. Diagnostic Feedback: Если возникла ошибка или неверный вывод, диагностический JSON автоматически передается на вход модели для самоисправления.
  5. Deployment: Проверенный код моментально передается на реальный контроллер или мобильное устройство.

🤖 TDscript AI-First Language Architecture

A programming language designed specifically for autonomous AI agents and local Large Language Models (3B–9B).

Why AI Needs Its Own Language

Traditional programming languages were designed for human developers, leading to hallucinations, dependency issues, and oversized token consumption when used with LLMs. TDscript AI-First eliminates imports, provides native hardware primitives, guarantees syntax through GBNF grammar, and enforces strict security via CapabilityScope.

Key Metrics from Benchmark

  • Average LOC: 3.5 – 5.6 lines per task (vs 8.5–9.7 in Python and 11–15 in C++).
  • Token Cost / Success: 2275 tokens (45% cheaper than traditional scripting).
  • Syntax Errors: 0% thanks to formal GBNF grammars.
  • Scope Safety: Automatic hardware sandbox intercepting unauthorized peripheral access.
