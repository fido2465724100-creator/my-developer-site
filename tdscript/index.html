⚡ О языке и платформе TDscript Спецификация Core 1.1 / Релиз v1.5.0

TDscript — это самостоятельный, полнофункциональный встраиваемый язык программирования и открытая программная экосистема, созданная Антоном Михайловым.

История и архитектурная независимость: В начале 2024 года первая базовая версия (Core 1.0 / v1.0.1) проектировалась как внутренний командный интерпретатор для Android-лаунчера Tdroid. Однако строгие требования к аппаратному управлению микросхемами (I2C, SPI, UART, CAN), промышленной телеметрии (Modbus TCP/RTU, ПЛК), робототехнике (ROS 2) и автономной самопочинке кода локальными нейросетями привели к полному выделению TDscript в самостоятельный универсальный язык программирования и платформу оркестрации аппаратуры (Спецификация Core 1.1, релиз v1.5.0).

4 столпа независимой экосистемы TDscript:
  • TDscript Core 1.1 VM & Байткод-компилятор: автономный сверхлегкий исполнитель, транслирующий код в компактный детерминированный байткод .tbc с криптографической проверкой цифровых подписей Ed25519, SHA-256 хешированием и лимитом выполнения (Step Limiter 10M). Нулевой оверхед видеопамяти (0 KB VRAM / Headless).
  • Кроссплатформенная среда TDscript Studio IDE (v1.1.0): отдельное приложение для настольных ПК (Linux DEB, RPM, AppImage, Tarball, Fat JAR) и мобильных устройств (Android APK) со встроенной поддержкой шинных переходников USB-OTG и Bluetooth LE.
  • Открытый SDK (библиотека TDModules): подключается как независимый встраиваемый рантайм в сторонние Java/Kotlin, Android, Linux и ROS 2 проекты. Лаунчер Tdroid — лишь один из прикладных клиентов, использующих этот движок.
  • AI-First агентный цикл: первая среда автоматизации, где генератором кода является LLM, а верификатором — строгая аппаратная песочница CapabilityScope с формальной GBNF-грамматикой и компактными однострочными ошибками ремонта.
Иерархия версий языка:
• TDscript v1.5.0 / Core 1.1 (Production-ready для встраиваемой оркестрации / Modern AI-First): основной релиз. Поддерживает hex-литералы (0x76, 0xD0), индексацию ByteArray[i], интерполяцию переменных в LString (запрет конкатенации +), сторожевой таймер WATCHDOG, пространственную песочницу CapabilityScope и формальную GBNF-грамматику.
• TDscript v1.0.1 / Core 1.0 (Архивная / Legacy Stable): ранняя редакция 2024 года, сохраняемая для 100% обратной совместимости старых скриптов в мобильном лаунчере Tdroid (десятичные адреса регистров, базовый LString без интерполяции, полный JSON ошибок).

⚡ About TDscript Platform Core 1.1 Specification / Release v1.5.0

TDscript is an independent, full-fledged embedded programming language and open software ecosystem created by Anton Mykhailov.

History & Architectural Independence: In early 2024, the initial dialect (Core 1.0 / v1.0.1) was designed as an internal terminal command engine for the Tdroid Android launcher. However, physical hardware orchestration demands (I2C, SPI, UART, CAN), industrial telemetry (Modbus TCP/RTU, PLCs), robotics (ROS 2), and autonomous closed-loop AI agent code repair led to the complete emergence of TDscript as an autonomous universal programming language & device orchestration platform (Core 1.1 Specification, Release v1.5.0).

4 Pillars of the Independent TDscript Ecosystem:
  • TDscript Core 1.1 VM & Bytecode Compiler: Standalone deterministic runtime compiling source code into compact binary .tbc bytecode with Ed25519 cryptographic signatures, SHA-256 integrity hashing, and 10M Step Limiting. Zero GPU memory overhead (0 KB VRAM / Headless).
  • Cross-Platform TDscript Studio IDE (v1.1.0): Standalone desktop app (Linux DEB, RPM, AppImage, Tarball, Fat JAR) and mobile app (Android APK) featuring direct hardware bus bridge support via USB-OTG and Bluetooth LE.
  • Embeddable SDK (TDModules Library): Connects as an independent runtime library into third-party Java/Kotlin, Android, Linux, and ROS 2 systems. The Tdroid launcher is merely one client application using this engine.
  • AI-First Agentic Loop: The first automation environment where code is generated by local LLMs and verified in a strict CapabilityScope sandbox with formal GBNF grammar and compact single-line repair diagnostics.
Language Version Hierarchy:
• TDscript v1.5.0 / Core 1.1 (Current Production Standard / AI-First): Primary production release. Supports hex literals (0x76, 0xD0), ByteArray[i] indexing, scoped LString variable interpolation (concatenation + prohibited), WATCHDOG timer, CapabilityScope sandboxing, and formal GBNF grammar.
• TDscript v1.0.1 / Core 1.0 (Archival / Legacy Stable): Early foundational 2024 dialect preserved for 100% backwards compatibility of legacy scripts in the Tdroid mobile launcher (decimal-only register addresses, basic LString without interpolation, full JSON diagnostics).

⚡ Über die TDscript-Plattform Core 1.1 Spezifikation / Release v1.5.0

TDscript ist eine eigenständige, vollwertige eingebettete Programmiersprache und ein offenes Software-Ökosystem von Anton Mykhailov für Geräte- und Chip-Orchestrierung.

Historische Evolution & Unabhängigkeit: Anfang 2024 entstand die Basisversion (Core 1.0 / v1.0.1) als interner Terminalbefehls-Interpreter für den Android-Launcher Tdroid. Durch die steigenden Anforderungen an physikalische Busse (I2C, SPI, UART, CAN), SPS-Steuerungen (Modbus TCP/RTU), Robotik (ROS 2) und autonome KI-Agenten entwickelte sich TDscript zu einer vollständig unabhängigen universellen Programmiersprache (Spezifikation Core 1.1, Release v1.5.0).

4 Säulen des TDscript-Ökosystems:
  • TDscript Core 1.1 VM & Bytecode-Compiler: Autonomer Laufzeitinterpreter, der Code in kompakten deterministischen .tbc-Bytecode mit Ed25519-Signaturprüfung und SHA-256-Hashing kompiliert. Null VRAM-Overhead (0 KB VRAM / Headless).
  • Plattformübergreifende TDscript Studio IDE (v1.1.0): Eigenständige Desktop-Anwendung (Linux DEB, RPM, AppImage, Tarball, Fat JAR) und mobile App (Android APK) mit Unterstützung von USB-OTG Bus-Bridges und BLE.
  • Einbettbares SDK (TDModules-Bibliothek): Unabhängige Laufzeitbibliothek zur Integration in beliebige Java/Kotlin-, Android-, Linux- und ROS 2-Projekte. Der Tdroid-Launcher ist lediglich ein Client.
  • AI-First Agentic Loop: Die erste Automatisierungsumgebung, in der Code durch LLMs generiert und in einer strikten CapabilityScope-Sandbox mit formaler GBNF-Grammatik repariert wird.
Hierarchie der Sprachversionen:
• TDscript v1.5.0 / Core 1.1 (Aktueller Industriestandard / AI-First): Hauptproduktions-Release. Enthält native Hexadezimal-Literale (0x76), ByteArray[i]-Indexierung, Variablen-Interpolation in LString, Watchdog und formale GBNF-Grammatik.
• TDscript v1.0.1 / Core 1.0 (Archiviert / Legacy-Stabil): Ursprüngliche Version (2024), aktiv im mobilen Launcher Tdroid für 100% Abwärtskompatibilität (Dezimalregister, Standard-LString, Voll-JSON).

⚡ Про мову та платформу TDscript Специфікація Core 1.1 / Реліз v1.5.0

TDscript — це самостійна, повнофункціональна вбудована мова програмування та відкрита програмна екосистема від Антона Михайлова.

Історія та архітектурна незалежність: На початку 2024 року базова версія (Core 1.0 / v1.0.1) створювалася як внутрішній інтерпретатор термінальних команд лаунчера Tdroid. Проте вимоги до прямого апаратного контролю мікросхем (I2C, SPI, UART, CAN), промислової телеметрії (Modbus TCP/RTU, ПЛК), робототехніки (ROS 2) та автономного самовідновлення коду локальними нейромережами перетворили TDscript на повноцінну незалежну платформу програмування (Специфікація Core 1.1, реліз v1.5.0).

4 опори незалежної екосистеми TDscript:
  • TDscript Core 1.1 VM & Байткод-компілятор: автономний детермінований рантайм, що компілює код у компактний байткод .tbc з перевіркою цифрових підписів Ed25519 та лімітом виконання (Step Limiter 10M). 0 КБ навантаження на GPU (0 KB VRAM / Headless).
  • Кросплатформна IDE TDscript Studio (v1.1.0): окремий додаток для ПК (Linux DEB, RPM, AppImage, Tarball, Fat JAR) та мобільних пристроїв (Android APK) з прямою підтримкою USB-OTG шинних адаптерів та Bluetooth LE.
  • Вбудований SDK (бібліотека TDModules): підключається як незалежний рантайм у сторонні системи на Java/Kotlin, Android, Linux та ROS 2. Лаунчер Tdroid — лише один з клієнтів.
  • AI-First агентний цикл: середовище, де код генерується локальними LLM та верифікується у суворій пісочниці CapabilityScope з формальною GBNF-граматикою та компактними помилками ремонту.
Ієрархія версій мови:
• TDscript v1.5.0 / Core 1.1 (Сучасний промисловий стандарт / AI-First): головний робочий реліз. Включає hex-літерали (0x76, 0xD0), індексацію ByteArray[i], інтерполяцію LString, сторож WATCHDOG, пісочницю CapabilityScope та GBNF-граматику.
• TDscript v1.0.1 / Core 1.0 (Архівна / Legacy Stable): рання базова редакція 2024 року, збережена для 100% сумісності старих скриптів у мобільному лаунчері Tdroid (десяткові адреси, базовий LString, повний JSON помилок).
