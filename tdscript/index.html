⚡ О платформе TDscript Core 1.1 / TDModules v1.4.0

TDscript (TextDroid Script) — легковесный детерминированный язык сценарного управления и программная экосистема, созданная Антоном Михайловым. Язык изначально проектировался для терминального лаунчера Tdroid, а затем развился в полноценную платформу оркестрации аппаратуры (Device & Chip Orchestration Platform): от физических шин микроконтроллеров (I2C, SPI, UART, CAN) и промышленных ПЛК (Modbus TCP/RTU) до робототехники (ROS 2/DDS) и автономных локальных ИИ-агентов с нулевым оверхедом видеопамяти (0 KB VRAM / Headless).

Статус версий экосистемы: В настоящее время в экосистеме сосуществуют две версии:
• TDscript v1.4.0 / Core 1.1 (Современная AI-First): используется в TDscript Studio IDE, стендах автоматизации и робототехнике. Поддерживает hex-литералы (0x76), индексацию ByteArray, интерполяцию LString, сторожевой таймер WATCHDOG и GBNF-грамматику для LLM.
• TDscript v1.0.1 / Core 1.0 (Классическая / Стабильная): сохраняется и поддерживается во всех ранее созданных утилитах автора, включая Android TUI лаунчер Tdroid и системные сервисы (десятичные адреса регистров, базовый LString, классический JSON ошибок).

⚡ About TDscript Platform Core 1.1 / TDModules v1.4.0

TDscript (TextDroid Script) is an ultra-lightweight deterministic scripting language and software ecosystem created by Anton Mykhailov. Initially designed for the Tdroid terminal launcher, it evolved into a complete hardware orchestration platform (Device & Chip Orchestration Platform): bridging physical microcontroller buses (I2C, SPI, UART, CAN), industrial PLCs (Modbus TCP/RTU), robotics (ROS 2/DDS), and autonomous local AI agents with 0 KB VRAM overhead.

Coexistence of Versions:
• TDscript v1.4.0 / Core 1.1 (Modern AI-First): Powering TDscript Studio IDE, robotics, and hardware testbenches. Features hex literals (0x76), ByteArray indexing, LString interpolation, fail-safe WATCHDOG, and GBNF grammar for local LLMs.
• TDscript v1.0.1 / Core 1.0 (Classic / Stable): Maintained in the Tdroid Android launcher and background system utilities (decimal register addresses, symbolic LString, full JSON diagnostics).

⚖️ Version Comparison: v1.4.0 (Studio) vs v1.0.1 (Legacy)

Feature / Subsystem TDscript v1.0.1 (Legacy / Tdroid) TDscript v1.4.0 / Core 1.1 (Studio / AI-First)
Primary Scope Tdroid TUI Launcher, Android background services, CLI TDscript Studio IDE (Linux/Android), Industrial PLC, Robotics
Numeric Literals Decimal only (e.g. 118, 208) Hexadecimal (0x76, 0xD0, 0xF4) & decimal
Byte Arrays (ByteArray) JVM pointer format [B@... Deterministic hex output [0x60], indexing bytes[i] (0..255)
Localization (LString) Symbolic L"KEY", concatenation prohibited Interpolation L"KEY:Temp is {temp}C", concatenation prohibited
Method Dispatch Unknown methods returned null Strict diagnostic error TDS_E106: unknown_method
Fail-Safe Watchdog Loop step limit (10M steps) WATCHDOG.feed() & WATCHDOG.emergencyStop()
Spatial Sandboxing Global capability bitmask CapabilityScope whitelisting (I2C: 0x76, Modbus: 100..200)
AI Diagnostics Full multi-line JSON Compact repair lines E104@1:5 exp=0x76 got=0x68 & GBNF grammar
